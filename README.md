# FaithLM: Towards Faithful Explanations for Large Language Models

This repository contains the refactored FaithLM framework, designed to evaluate the fidelity of explanations generated by Large Language Models.

## Quick Start for Team Members

To allow everyone to experiment with different combinations of Predictor and Explainer models, we have centralized the execution logic into a single flexible bash script.

### 1. Setup Environment
First, ensure you have the `nlp_final` conda environment set up with all required dependencies:
```bash
conda create -n nlp_final python=3.10
conda activate nlp_final
pip install -r requirements.txt
```

### 2. Configure API Keys
You must create a `.env` file in the root directory to store your API keys. Do **not** commit this file to git!
```env
DEEPSEEK_API_KEY="sk-..."
# Add Claude/OpenAI keys if testing those models
```

### 3. Run an Experiment Variant
You can kick off a full pipeline run (Local + Global optimization) using the `run_experiment.sh` script. Pass the Dataset, Predictor Model, and Explainer Model as arguments:

```bash
conda run -n nlp_final bash scripts/run_experiment.sh [DATASET] [PRED_MODEL] [XAI_MODEL]

# Example:
conda run -n nlp_final bash scripts/run_experiment.sh xcopa_vi qwen deepseek
```

**Where do results go?**
The script automatically provisions a unique directory for your specific variant inside `results/experiments/` (e.g., `results/experiments/xcopa_vi_qwen_deepseek/`). This ensures your experimental data does not collide with your teammates' data.
